## CI E0463（can't find crate for `easytier`）排查
- 用户贴出 ET Test 失败日志：easytier 包内两个 bin（easytier-core / easytier-cli）报 E0463。
- 根因：GHA rust-cache 缓存的 target/ 被取消的运行污染成半成品，cargo 判定 easytier lib Fresh 但 rmeta 缺失 → bin 找不到 lib。
- 修复已在 dev：c7f20da4（test.yml 改 registry-only 缓存，cache-targets=false），已推送 origin/dev。
- 隐患：main、releases/v2.7.1、releases/v2.7.10 均未包含该修复；release 分支 push 触发 test.yml，若 Cargo.lock/rustc 未变会恢复同一个被污染的 cache key，E0463 可能复发 → 需 cherry-pick c7f20da4 或 gh cache delete 清缓存。
- 本地 Windows 复现被无关问题挡住：zstd-sys 构建时 MSVC cl.exe 全部 exit code 2（本地 VS BuildTools 环境问题），与 CI 错误无关。
