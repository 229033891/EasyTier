## 前端：DNS 策略面板去掉「+配置策略」按钮（方案 A）

用户嫌多一次点击。改的是 `easytier-web/frontend-lib/src/components/Config.vue`：

- 原来 DNS 面板是 `v-if="curNetwork.dns_config"` 显示三个编辑器 / `v-else` 显示「+配置策略」按钮；按钮唯一作用就是把 `dns_config` 初始化成空对象。
- 现在删掉 `v-else` 分支（按钮 + `initDnsHosts()`），编辑器常显。`v-if` 保留，**只为类型收窄**（`curNetwork.dns_config` 是 optional，去掉会让 vue-tsc 报 possibly undefined）。
- `syncNormalizedNetwork()` 里补一句 `ensureDnsConfig()`（`watch(..., {immediate:true})` 已经在跑，覆盖进页面/切网络两条路径）。
- 顺带删掉死掉的 i18n key `dns.hosts.enable` / `dns.hosts.enable_tip`（cn + en）。

**已知代价（用户接受）**：进过配置页的网络，保存时会带一个空 `dns_config`（`Some(empty)`），"没配过" 和 "配了但是空的" 不再区分。后端语义是 `Some(empty)` = 清空策略（`runtime_reconcile.rs:401` 注释），落到节点等价于回落系统 DNS，无害；`<2.7.4` 老客户端本来跳过该字段。**没有**加「空则回落 None」（那是方案 B，用户没选）。
