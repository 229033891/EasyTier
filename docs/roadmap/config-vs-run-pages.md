## 1. 目标模型

两端（Web / GUI）统一为 **两个页面、两种职责**：

| 页面 | 只管什么 | 底部主区 |
|------|----------|----------|
| **运行页（状态）** | 看运行信息；启停网络 | **启动 / 停止（禁用）**；入口「节点配置」 |
| **配置页** | 改参数；落盘 / 丢弃草稿 | 脏：**取消编辑 + 保存**；干净：**返回运行页**（无启停主按钮） |

一句话：配置页不抢「跑/停」；运行页不开放编辑配置（停止态可只读预览）。

```text
运行页 ──「节点配置」──► 配置页
  ▲                      │
  └────「返回运行」/ 保存后返回 ◄─┘
  │
  └── 启动 / 停止（仅此页）
```

## 2. 相对现状

| 端 | 现状 | 与目标差距 |
|----|------|------------|
| **Web** | 已有 `?mode=status\|config` 双入口 | 配置模式下底部仍可能出现「运行网络」类主操作；停止态 status 为空态提示后可再对齐文案 |
| **GUI combined** | 同一壳内用 `isEditingNetwork` 切换；停止态直接 `showConfigPanel`；配置可见时 `stickyFooterPrimary === 'run'` | 停止态默认落在配置；配置页挂「运行网络」；与「双页职责」不一致 |

本文不要求 GUI 必须改成两个路由，**同一壳内切换亦可**，但底部按钮与进入/退出规则须与上表一致。

## 3. 停止态（运行数据没有，配置仍可看）

运行中才有 peer / 延迟 / 路由等；停止后**运行态内容**为空，但应展示**当前已保存配置的只读预览**，避免「页面空白、不知道会以什么配置启动」。

停止态运行页：

- 提示：已停止 + 下方只读
- **只读**配置表单（不可改、无工具栏 / 无保存）
- 主按钮：**启动**
- 次按钮：**节点配置**（进可编辑配置页）

配置仍只在配置页编辑；启动成功后再回到有运行数据的运行页。

---

## 4. 多端同步：可行且合理

| 对象 | 是否跨端同步 | 说明 |
|------|--------------|------|
| 当前在配置页还是运行页 | **否** | 纯本地导航；Web/GUI/多窗口可各看各的 |
| 未保存草稿（脏） | **否** | 只留本机；禁止多端同步脏草稿 |
| 网络运行 / 停止 | **是**（已有） | `list_network_instance_ids` 等 |
| 已保存配置 | **是**（已有） | `save_config` / 托管拉取 |

并发时（A 保存、B 保存；A 停、B 启）沿用现有冲突 / 后写覆盖语义即可，**不必为拆页发明「页面级同步」**。把启停收拢到运行页，反而减少两端同时误点「运行网络」的机会。

## 5. 底部栏规则（验收用）

### 5.1 运行页

- 运行中：主操作 **停止（禁用）**；次操作 **节点配置**（及系统设置等壳层按钮）
- 已停止：主操作 **启动**；次操作 **节点配置**
- **不出现**：保存、取消编辑（无配置草稿上下文）

### 5.2 配置页

- 脏：同时显示 **取消编辑** + **保存**（成对出现/消失）
- 干净：显示 **返回运行页**（或 Web 的「前往状态」）；**不**单独显示「取消编辑」
- **不出现**（目标态）：「运行网络 / 启动 / 停止」作为配置页主按钮  
  - 过渡期若保留「保存并运行」，须为次要入口且运行中重建要确认（见前置文档）

### 5.3 与已落地文案的关系

- 「取消编辑」= 脏时重拉已保存配置（真还原）
- 「返回运行页」= 干净时退出编辑 / `mode=status`，不重拉
- 窄屏：配置页按钮可等分单行、去图标留字（已部分落地）

## 6. 落地顺序

1. **GUI combined 运行中**：**已做** — 配置页无「运行网络」；运行页「禁用网络」+「节点配置」；干净编辑「返回运行」。
2. **GUI 停止态**：**已做** — 默认运行空态（启动 + 节点配置）；点「节点配置」再进表单。
3. **Web 对齐**：`mode=config` 已不再挂启停主按钮（与 stickyFooterPrimary 共用逻辑）；`mode=status` 保持启停 + 切配置。
4. **验收**：双端截屏（运行中 / 停止 / 配置脏 / 配置干净）；多窗口同时打开不要求页签一致，只要求启停与已保存配置一致。
5. **可选后续**：配置页次要「保存并运行 / 应用并重启」（运行中须确认断流）。

## 7. 非目标

- 不强制 GUI 拆成两个 URL（可用壳内状态模拟双页）
- 不做跨端「当前页签」同步
- 不在本项重做脏检测算法（沿用 `config-dirty`）
- 产品帮助文案在代码落地前不写成本文目标态（索引约定：Roadmap ≠ Current）
